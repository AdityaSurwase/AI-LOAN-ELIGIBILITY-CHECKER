# AI Loan Eligibility Checker

A sleek, single-page web application designed to help users calculate loan eligibility, estimate credit scores, compute EMIs, and receive AI-driven financial insights[cite: 2].

## Features

- **Loan Eligibility Checker:** Evaluates user income, existing obligations, and credit scores against a 50% fixed-obligation-to-income cap[cite: 2].
- **Credit Score Analyzer:** Generates a rough estimate score (300–900 scale) based on payment history, credit utilization, history length, and enquiries[cite: 2].
- **EMI Calculator:** Instantly calculates monthly installment amounts, principal-to-interest breakdowns, and total repayment costs[cite: 2].
- **AI Financial Insights:** Integrates with the Anthropic Claude API to provide personalized tips and risk assessments[cite: 2].
- **Data Logging:** Tracks recent checks locally via `localStorage` with optional Google Sheets Web App integration[cite: 2].

## Getting Started

1. Clone or download the repository.
2. Open `index.html` directly in any modern web browser.
3. (Optional) Click the **⚙ Settings** button in the top right to configure your Claude API key or Google Sheets Web App URL[cite: 2].

## Disclaimer
*Estimates only, not formal financial advice[cite: 2].*
